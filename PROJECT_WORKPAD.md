## Project Goal

Build a mobile-compatible single-page activity website for WaytoAGI AI 切磋大会第 26 期 · 博物馆奇妙日清迈场. The page should attract visitors, explain the event, make the participation path clear, help people choose a museum, accept pattern collections, generate a downloadable numbered card, and maintain a public newest-first Lanna pattern archive.

## Scope

### In Scope

- CMI Community navigation identity and WaytoAGI initiator credit.
- Hero, artistic activity manifesto, fishbone participation flow, and full event-day schedule.
- Full-screen interactive museum selection for Lanna Folklife Centre and FAM Fahlanna Art Museum.
- Direct WeChat group QR registration.
- Access-code-protected pattern collection with multiple detail and context images.
- Downloadable numbered pattern card and public square archive grid.
- Responsive desktop and mobile interaction states.
- Supabase schema, storage, RLS, and Edge Function contract.

### Out of Scope

- A separate admin dashboard in v1.
- Cultural or historical claims generated by AI.
- Automatic museum-object recognition.
- Live public submissions before the user approves a Supabase project and event access code.
